# Support

Report bugs and request features through the [GitHub issue tracker](https://github.com/mm-lab-dev/browser-mcp-debug/issues).

For a connection or debugging problem, include:

- Browser MCP Debug, VS Code, Chrome, and local Node.js versions.
- Local or Remote-SSH use, and the operating systems on each side.
- A minimal `browser-mcp` configuration and the Chrome launch configuration it wraps.
- The relevant **Output > Browser MCP** messages and steps to reproduce.
- Whether the original Chrome configuration works without Browser MCP Debug.
- For a remote MCP client, the forwarding configuration and which endpoint cannot be reached.

Remove credentials, tokens, private hostnames, URLs, browser data, and proprietary source before sharing. Heap snapshots and browser profiles can contain page content and authentication data; provide a small reproducible example rather than uploading them.

This is an independent extension. It is not an official product of Microsoft or Google. Playwright MCP and Chrome DevTools MCP are separate upstream projects downloaded through the configured local commands.
